Research

Academic contributions to agricultural data science

🔬 Crop Classification & Yield Prediction Using Robust ML Models

My research focuses on applying machine learning to agricultural sustainability. Using a dataset of environmental features (N, P, K, temperature, humidity, pH, rainfall), I built and optimized multiple classification models including Random Forest, XGBoost, SVM, KNN, and Logistic Regression with RandomizedSearchCV hyperparameter tuning.

The pipeline includes data preprocessing, EDA with pairplots/histograms/correlation matrices/boxplots, feature selection, 80/20 train-test split, model evaluation with accuracy, precision, recall, and confusion matrices.
